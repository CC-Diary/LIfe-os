# 数字分身设计原则

本设计吸收公开项目中关于个人判断模型的通用方法，不复制第三方代码、文案、品牌、图片或界面素材。研究重点参考 SkyTwin、DigitalTwin、LifeOS 等公开项目；任何未来代码依赖仍须单独做许可证清单。

## 核心模型

数字分身不是一个固定人格提示词，而是一个可检查、可修正、随时间变化的个人判断模型：

`经历 -> 价值与约束 -> 行为证据 -> 决策模式 -> 当前建议 -> 结果校准`

机器模型对应六类对象：`Event`、`Value`、`Pattern`、`Decision`、`Outcome`、`BeliefChange`。对象之间通过 ID 和 evidence_ids 连接；摘要不能替代原始事件。

计划和近期状态单独使用 `Plan` 对象，形成 `Plan -> Observation -> Outcome` 链。计划不是事实，未完成不是人格证据；只有跨时间、跨情境且经用户确认的模式，才可进入长期判断模型。

## 借鉴并落地的机制

- **证据化偏好**：每个长期判断包含原始证据、来源、时间、置信度、反例和当前状态。
- **可纠正记忆**：用户可以批准、修改、否定或删除 AI 的记忆；更正不覆盖历史证据。
- **分领域信任**：职业、财务、关系、健康等领域分别维护信任和授权，不因一个领域的准确而自动扩大权限。
- **解释记录**：每个重要建议列出使用的资料、假设、未知项、选项和改变结论的条件。
- **渐进授权**：默认只观察和建议；涉及外部写入、发送、购买、删除或不可逆行动时必须单独确认。
- **结果校准**：登记用户采纳的选择、结果和偏差，用于修正模型，不把一次成功当成永久准确。
- **本地优先**：档案文件是事实源，模型只是分析层；不依赖特定供应商。

## 不承诺

不声称百分之百复制一个人、不声称必然预测未来、不把推测写成事实、不以历史行为锁定用户未来。外部事实与专业领域问题仍需当前来源和专业判断。

## 新增研究对象

- **SkyTwin**：最接近“学习个人判断”的产品模型；重点参考证据、置信度、反例、分领域信任、解释记录和渐进授权。Apache-2.0，可商用，但复制代码须保留许可。
- **PersonalOS**：适合参考本地个人上下文、决策支持、可审查记忆和一次性 onboarding；GPL-3.0，仅研究思想，不作为实现依赖。
- **decision-brief**：适合参考结构化决策记录和本地优先决策界面；MIT，可商用，但它是决策工具，不是完整人生分身。
- **You-AI**：提出从个人写作学习人格并生成决策与计划，但许可证和第三方资产需要逐项核实，暂不作为依赖。
- **LifeOS（siddath）**：适合参考纯文本人生档案、数据 schema 和 AI 读取合同；MIT，可商用但复制代码须保留许可。

## 继续坚持的边界

研究“如何建模个人判断”可以借鉴；实现时保持原创的数据结构、访谈协议、提示词、界面和代码。任何外部代码先经过许可证、依赖和版权清单检查。

## 针对当前瓶颈的研究结论

- **TESSERA**（MIT）：最适合参考文本优先、来源级 provenance、可解释检索和时间变化；把“能找到一段相似文字”提升为“能回指哪份原始证据”。
- **Neo4j Agent Memory / Agent Memory TCK**（Apache-2.0）：适合参考跨 Agent 共享、短期/长期/推理记忆分层和可执行兼容性测试；不直接绑定 hosted 服务，先研究其规范和测试场景。
- **AgenticMemory**：提出决策→事实→观察的因果链、supersedes 修正链和时间查询；仓库许可证需在采用前单独核验，因此当前只作为概念研究。
- **Temporal Belief Graph 的失败复盘**：提醒我们不要假设复杂信念图必然比简单检索更准确。任何新结构都必须用时间切分和反事实案例证明改进，否则保持简单。

因此，突破路径不是继续扩充人格标签，而是实现三项可验证能力：证据回指、跨 Agent 一致读取、时间切分回测。
