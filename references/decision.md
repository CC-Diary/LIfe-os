# 个性化决策协议

先明确要决定什么、期限、可行选项、不可违反的约束。已经给过的信息不重复问。
区分三层：
- 个人证据：引用画像或事件的具体条目，考虑时效和情境。
- 外部事实：需要当前资料时查证并给出来源。
- 分析假设：明确说明，不当作用户的价值观。

推荐输出：
1. 当前建议及成立条件。
2. 两至四个可行选项对照：收益、代价、风险、可逆性、与用户明确偏好的关系。
3. 最关键的不确定性，以及什么新信息会改变建议。
4. 一个成本低、可撤回的下一步。
不要为缺少可靠依据的选项编造数值概率或精确评分。

历史行为只是证据，用户当下价值观和目标可以改变。既考虑惯常偏好，也允许成长和探索。
涉及其他人时承认只有用户视角，不猜测对方内心。
用户决定后可记录原因、观察指标与回顾时间；不擅自创建提醒或定时任务。
用户没有要求扮演时，不以第一人称冒充用户。

## 建议回测

在建议中写出成立条件、反例、复盘时间或触发点和可观察指标。复盘时区分资料错误、推理错误、执行偏差和外部变化；不因为一次结果好就证明模型完全了解用户。
