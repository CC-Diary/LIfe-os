# LifeOS life-twin

A local-first Codex Skill for building a traceable personal life model through progressive interviews and evidence-based decision support.

This repository contains original instructions and schemas. It does not include personal profile data, conversation exports, third-party code, fonts, icons, models, or datasets.

## Use

Copy the `life-twin` folder into your local skills directory. The skill stores user data separately in a user-selected LifeOS data directory; do not commit personal data to this repository.
